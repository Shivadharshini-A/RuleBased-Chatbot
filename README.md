# Rule-Based AI Chatbot

## Project Overview
This project implements a simple rule-based chatbot using Python. It responds to predefined user inputs using a dictionary of responses and conditional logic.

## Features
- Greeting and conversational responses
- Predefined questions and answers
- Case-insensitive input handling
- Removal of unnecessary spaces
- Continuous conversation using a while loop
- Exit commands: `exit`, `bye`, and `quit`
- Fallback responses for unknown inputs
- Help command for suggested questions

## Technologies Used
- Python
- Dictionaries
- Conditional statements
- Loops
- Functions

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the integrated terminal.
4. Run the following command:

   `python chatbot.py`

## Conclusion
This project demonstrates fundamental Python programming concepts used to build a simple rule-based conversational system.
